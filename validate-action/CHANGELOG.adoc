=== [1.0.0] - 2026-05-29

==== Added

* Initial Marketplace-ready composite action for validating `+.a2ml+`
manifests.
* Configurable `+path+`, `+strict+`, and `+paths-ignore+` inputs.
* GitHub Actions outputs for scanned files, validation errors, and
warnings.

==== Fixed

* Allow local smoke runs outside GitHub Actions by defaulting missing
`+GITHUB_OUTPUT+` to `+/dev/null+`.
